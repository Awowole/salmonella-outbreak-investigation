# Salmonella Outbreak Investigation Using R

## Overview

This project investigates a simulated Salmonella outbreak using statistical methods in R. The objective is to identify the major risk factors associated with infection through exploratory data analysis, hypothesis testing, and logistic regression.

## Objectives

- Investigate factors associated with Salmonella infection.
- Explore demographic and dietary characteristics.
- Perform descriptive and inferential statistical analyses.
- Build a logistic regression model to identify significant predictors.

## Dataset

- Sample Size: 1,000 individuals
- Dataset Type: Simulated outbreak dataset

## Variables

- Age
- Gender
- State
- Ate Seafood
- Ate Meat
- Ate Fish
- Ate Eggs
- Ate Raw Vegetables
- Infection Status

## Statistical Methods

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Descriptive Statistics
- Chi-square Test
- Independent Samples t-test
- Multiple Logistic Regression
- Odds Ratio Estimation

## Software

- R
- RStudio

## Key Findings

Seafood consumption was identified as the only statistically significant predictor of Salmonella infection after adjusting for other variables using multiple logistic regression.
